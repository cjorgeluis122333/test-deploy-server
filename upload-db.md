```
https://tidbcloud.com/
```

## Step 1: Create a cluster

1. Change the cluster name
2. Select a region more zoom of your location

## Step 2: Create the Database
1. Inicia sesión en TiDB Cloud.
2. Haz clic en el nombre de tu Cluster (el que creamos al principio).
3. En el menú lateral o superior, busca la pestaña que dice"SQL Editor".
4. Se abrirá una consola donde puedes escribir código SQL. Escribe lo siguiente:

```mysql
CREATE DATABASE nombre_de_tu_base_de_datos;
```
## Step 3: Upload your database
1. Push the button connect
2. Select the database do you create in database
3. Push in generate password
4. Save the information of parameter
5. (Optional) Save to the Connection String
